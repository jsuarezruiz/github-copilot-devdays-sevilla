STEPS
1. In the app, pick 03b-hierarchy and press ⌘N.
2. First time only: answer A to "Trust this repository?", then press ⌘N again.
3. Send Hi, wait for the reply, then type the agent command and press Enter.
   The chip lists: Default agent, coder, orchestrator, planner, reviewer.
4. Paste the prompt and explain the hierarchy while it runs.

with the three models and the verdict (PASS in the last run).

RESET (terminal, always: the coder edits files)
git -C ~/copilot-talk/03b-hierarchy reset -q --hard && git -C ~/copilot-talk/03b-hierarchy clean -fdq

IF IT GOES WRONG
A subagent doesn't start: its model isn't on your account. Edit the model field of
that agent file in the project folder, using a name from the model picker.
