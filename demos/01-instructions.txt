PROMPT
What rules should I follow when I change the UI in this repo? Answer in at most five short bullets. If the repo states no rules, say so.

YOU SHOULD SEE (about 25 s)
The team's rules, led by what demo 0 could not guess: PascalCase ids that end
with the control type (GreetButton, NameBox), never change an existing
AutomationId, visible text in English, and dotnet build
src/SampleApp/SampleApp.csproj after a change. Also: every interactive control
has Name and a matching AutomationProperties.AutomationId. Demo 0 may have
hinted at that one from the docs, but only here is it a rule.
