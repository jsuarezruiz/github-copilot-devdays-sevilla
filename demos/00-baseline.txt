Project ~/copilot-talk/00-baseline · slide 6 · slot 2 min

MODEL: local (qwen3.6:35b, effort None) or Auto. Local takes about 2 min.

STEPS
1. In the app, pick 00-baseline and press ⌘N.
2. First time only: answer A to "Trust this repository?", then press ⌘N again.
3. Paste the prompt. If the agent asks to run a command that lists files, press Enter.

PROMPT
What rules should I follow when I change the UI in this repo? Answer in at most five short bullets. If the repo states no rules, say so.

YOU SHOULD SEE (about 40 s)
"There are no UI-specific rules in this repo", then generic advice taken from the
folder layout: keep the UI in src/, run the tests, update the docs.

OPTIONAL SECOND PROMPT: the Clear button (30 s to 2.5 min, skip it if you are short of time)
Add a Clear button to SampleApp that empties the name and the greeting. Check that it works.

Click the Changes chip to show the diff. The button often already has Name="ClearButton"
and AutomationProperties.AutomationId="ClearButton": the point is that nothing makes it a rule.

RESET (terminal, after the Clear button: demo 10 uses this folder too)
git -C ~/copilot-talk/00-baseline reset -q --hard && git -C ~/copilot-talk/00-baseline clean -fdq
